# Chapter 8 – Mathematics Review Practice

This folder contains a structured hand‑over of the practice questions from **Chapter 8 – Mathematics Review — Practice** of the Pascal GRE preparation book.  The chapter is divided into three quantitative sections covering **Algebra and Arithmetic (8.1)**, **Geometry (8.2)** and **Data Analysis (8.3)**.  Each section contains quantitative comparison questions, single‑answer multiple‑choice questions, multiple‑select questions and numeric‑entry problems.

Files in this directory:

| File name | Description |
|---|---|
| **chapter‑08‑raw‑extraction.md** | Complete transcription of every practice question (all 60 questions) in the order presented in the book.  Each entry notes the source page and reproduces the full text of the question, answer choices and a description of any accompanying figures or tables. |
| **chapter‑08‑full‑solutions.md** | Detailed solutions for every question.  Each solution specifies the source page and topic, restates the prompt, lists the choices, identifies the correct answer, summarises the given information, states what is being asked, and demonstrates step‑by‑step how to arrive at the solution.  Where appropriate, GRE‑style shortcuts, common traps and reasoning about wrong answers are provided.  A confidence rating is included for each solution. |
| **chapter‑08‑data.json** | A machine‑readable JSON representation of each question and its solution.  Fields include the question ID, chapter, question number, type, topic, source page, prompt, choices, correct answer, formulas used, solution steps, tips, traps, wrong answer analyses, final answer and confidence level. |
| **chapter‑08‑status.md** | A summary of the extraction and solution process, including the number of questions found, the number solved, any items requiring review, and an inventory table with status and confidence for each question. |
| **chapter‑08‑needs‑review.md** | A list of any items that could not be read clearly or solved with high confidence.  If there are no such items, the file states that nothing needs review. |

All files are provided in Markdown or JSON format as appropriate so that they can be easily read by both humans and machines.  Diagrams and tables from the original book are described verbally in the raw extraction file.  For further guidance on the solutions or to raise any questions, please refer to the full solutions file.
