# Chapter 5 – Logic‑Based Reading Comprehension

This repository contains the complete extraction and analysis of every question in **Chapter 5** of the GRE Pascal Book.  The chapter covers *logic‑based reading comprehension* questions, including additional facts, assumptions, conclusions, argument completions and argument structure.  The files in this directory document each question’s passage, question stem, answer choices, correct answer, reasoning and related metadata.  They are intended as a thorough reference for students and instructors alike.

### Directory contents

| File | Description |
|---|---|
| **chapter‑05‑raw‑extraction.md** | A sequential listing of all 30 questions.  For each question the file records the source page, the full original passage or prompt, the question stem and all answer choices.  No analysis is provided here. |
| **chapter‑05‑full‑explanations.md** | Detailed solutions for every question.  Each entry includes an argument map, keyword table, logic discussion, why the correct answer works, why each other option is wrong, and a confidence rating. |
| **chapter‑05‑data.json** | Structured JSON data capturing the key attributes of each question—identifier, source, text, choices, correct answer, reasoning, clue keywords and tags.  This file facilitates programmatic consumption of the chapter’s contents. |
| **chapter‑05‑status.md** | A summary of the work completed.  It notes how many questions were found, solved and any that require further review. |
| **chapter‑05‑needs‑review.md** | Lists any questions or pages that require further examination due to unreadable text or uncertain answers.  If no items need review this file simply states that none exist. |

All files are assembled into the ZIP archive `chapter‑05‑logic‑based‑reading‑handover.zip` for convenient download.
