# Chapter 9 – Quantitative Practice Sets

This directory contains all processed material for **Chapter 9** of the GRE Pascal book, which presents multiple quantitative practice sets.  Each practice set includes a mixture of quantitative‑comparison, multiple‑choice, multi‑answer and numeric‑entry questions.  The files here provide an inventory of the questions, raw extraction notes, complete solutions, structured data and a status overview.

## Files

| File | Purpose |
|---|---|
| **chapter-09-inventory.md** | Catalogues each practice set and lists the number and type of questions contained in it. |
| **chapter-09-status.md** | Summarises the extraction status, including the number of questions found, solved and any unresolved issues. |
| **chapter-09-raw-extraction.md** | Presents bullet‑level summaries of the question stems and answers as they were extracted from the scanned pages.  Page references and image paths are provided where available. |
| **chapter-09-full-solutions.md** | Provides detailed, step‑by‑step solutions for every practice question, including definitions of key concepts and GRE‑specific reasoning tips. |
| **chapter-09-data.json** | Machine‑readable dataset of all questions, answers, types and keywords.  Useful for programmatic parsing or building an application. |
| **chapter-09-needs-review.md** | Lists any questions, options or text that were unclear in the scans and should be verified against the original book. |

The early practice sets (Sets 1–3) are fully solved, but the later sets (Sets 4–6) contain many unsolved questions.  See the status and needs‑review files for details.  Use the inventory and status files to get an overview, the raw extraction and full solutions for the solved content, and the JSON file for data‑driven applications.
