# GRE Book Simulator

Deployable React and Vite package for GitHub, Vercel, Netlify, and other static hosts.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm install
npm run build
npm run preview
```

## Deploy

### Vercel
- Import the repository
- Framework preset: `Vite`
- Build command: `npm run build`
- Output directory: `dist`

### Netlify
- Build command: `npm run build`
- Publish directory: `dist`

### Other static hosts
- Run `npm run build`
- Upload the `dist` folder

## Notes
- Figure-based quantitative items are preserved with source page references.
- Vocabulary appendix pages are indexed by page and word range.
